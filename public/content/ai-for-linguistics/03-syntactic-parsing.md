# Syntactic Parsing: From Context-Free Grammars to Neural Constituency Parsers

## Overview

Syntax is the study of how words combine to form grammatical phrases and sentences. A **parser** is an algorithm that takes a sequence of words and produces a structural representation — the grammatical backbone of a sentence. Syntactic parsing is one of the oldest and most central problems in computational linguistics, and its history traces almost the entire arc of the field itself.

Constituency parsing organizes words into nested **constituents** (phrases) using a phrase structure grammar. The sentence *The cat sat on the mat* is parsed into a tree where noun phrases (NP) like *The cat* combine with verb phrases (VP) like *sat on the mat*, ultimately combining into a sentence (S). This hierarchical structure captures how words group and nest.

---

## Context-Free Grammars

The standard formal foundation for constituency parsing is the **context-free grammar (CFG)**. A CFG $G$ is a 4-tuple $(N, \Sigma, R, S)$:

- $N$ is a set of non-terminal symbols (phrasal categories: S, NP, VP, DT, NN, ...)
- $\Sigma$ is a set of terminal symbols (actual words)
- $R$ is a set of rewrite rules of the form $A \rightarrow \alpha$ where $A \in N$ and $\alpha \in (N \cup \Sigma)*$
- $S \in N$ is the start symbol

The language generated by a CFG is the set of all strings derivable from $S$ using the rules.

English has roughly 20-30 phrasal categories and hundreds of lexical rules. A fragment of English grammar:

```
S  → NP VP
NP → DT NN
NP → DT JJ NN
VP → VBD PP
VP → VBD NP
PP → IN NP
DT → the | a | an
NN → cat | dog | mat
VBD → sat | ate
IN → on | in | with
```

A **parse tree** is the result of recursively applying these rules until only terminals remain.

## Parsing Algorithms

### CYK Algorithm

The Cocke-Younger-Kasami (CYK) algorithm parses strings in $O(n^3 \cdot |R|)$ time using dynamic programming. It requires the grammar to be in **Chomsky Normal Form (CNF)**: rules are either $A \rightarrow B C$ (binary) or $A \rightarrow a$ (terminal).

The algorithm fills a dynamic programming table $T[i, j]$ with the set of non-terminals that can generate the substring from position $i$ to $j$.

```python
def cyk_parse(words, grammar):
    """
    CYK parsing algorithm.
    grammar: dict mapping non-terminals to lists of RHS (either terminals or pairs)
    Returns: parse table T[i][j] = set of non-terminals for span [i, j)
    """
    n = len(words)
    # T[i][j] = set of non-terminals that generate words[i:j]
    T = [[set() for _ in range(n + 1)] for _ in range(n)]

    # Rule 1: Terminal productions (A -> word)
    for i, word in enumerate(words):
        for A, productions in grammar.items():
            if word in productions:
                T[i][i + 1].add(A)

    # Rule 2: Binary productions (A -> B C), fill larger spans
    for length in range(2, n + 1):          # span length
        for i in range(n - length + 1):     # start position
            j = i + length
            for k in range(i + 1, j):       # split point
                for A, productions in grammar.items():
                    for prod in productions:
                        if isinstance(prod, tuple) and len(prod) == 2:
                            B, C = prod
                            if B in T[i][k] and C in T[k][j]:
                                T[i][j].add(A)

    return T

# Example grammar (simplified English fragment)
grammar = {
    'S':  [['NP', 'VP']],
    'NP': [['DT', 'NN'], ['DT', 'JJ', 'NN'], ['NN']],
    'VP': [['VBD', 'PP'], ['VBD', 'NP']],
    'PP': [['IN', 'NP']],
    'DT': {'the', 'a'},
    'NN': {'cat', 'dog', 'mat'},
    'VBD': {'sat', 'ate'},
    'IN': {'on', 'in'},
    'JJ': {'big', 'small'},
}

words = ['the', 'cat', 'sat', 'on', 'the', 'mat']
T = cyk_parse(words, grammar)
print(f"'the cat sat on the mat' is a valid S: {'S' in T[0][6]}")
```

### Shift-Reduce Parsing

**Shift-reduce parsers** are bottom-up, left-to-right parsers that use a stack and an input buffer. They are more natural for online processing and can be extended to neural sequence models. The basic actions:

- **Shift**: Move the next word from the input buffer to the stack
- **Reduce**: Pop right-hand-side symbols from the stack and push the left-hand-side non-terminal

Modern neural shift-reduce parsers (e.g., the parser in the paper "A Fast and Accurate Dependency Parser" by Chen & Manning, 2014) use a feedforward network to score actions at each step.

## Neural Constituency Parsers

Modern constituency parsers use neural sequence models to score trees directly. The **ChartParser** approach treats parsing as agenda-based dynamic programming where a neural network scores each candidate constituent.

The parsing algorithm maintains an agenda of candidate spans (start, end, category, score). At each step, it pops the highest-scoring item, expands it by considering splits (for non-terminals) or shifts (for terminals), and adds new candidates to the agenda.

```python
import torch
import torch.nn as nn

class NeuralChartParser(nn.Module):
    """
    Neural constituency parser using span scoring.
    For each span (i, j) and category, predict a score.
    Then use dynamic programming (CKY) to find the best tree.
    """
    def __init__(self, vocab_size, tag_vocab_size, embed_dim=256, hidden_dim=256, num_categories=50):
        super().__init__()
        self.word_embed = nn.Embedding(vocab_size, embed_dim)
        self.pos_embed = nn.Embedding(tag_vocab_size, embed_dim)
        self.span_repr = nn.Sequential(
            nn.Linear(embed_dim * 4, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
        )
        self.category_head = nn.Linear(hidden_dim, num_categories)

    def get_span_features(self, word_embeds, pos_embeds, i, j):
        """Extract features for span [i, j)"""
        left  = word_embeds[i]
        right = word_embeds[j - 1]
        # Boundary representations
        span_rep = torch.cat([left, right, left * right, left - right], dim=-1)
        return self.span_repr(span_rep)

    def score_constituents(self, word_ids, pos_ids):
        """Score all constituents in a sentence"""
        word_embeds = self.word_embed(word_ids)
        pos_embeds  = self.pos_embed(pos_ids)
        embeds      = word_embeds + pos_embeds  # [seq_len, embed_dim]
        n = embeds.size(0)

        # For each span [i, j), predict category scores
        scores = {}  # (i, j) -> tensor of category scores
        for i in range(n):
            for j in range(i + 1, n + 1):
                span_features = self.get_span_features(embeds, pos_embeds, i, j)
                scores[(i, j)] = self.category_head(span_features)
        return scores

# CKY decoding with neural scores
def cky_decode(scores, n, num_categories):
    """Find best parse tree using CKY with neural scores"""
    # Best[i][j] = (best_category, best_left_child_idx, best_right_child_idx, best_score)
    best = [[(None, None, None, float('-inf')) for _ in range(n + 1)] for _ in range(n)]

    for i in range(n):
        for cat_id in range(num_categories):
            s = scores[(i, i + 1)][cat_id].item()
            if s > best[i][i + 1][3]:
                best[i][i + 1] = (cat_id, None, None, s)

    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length
            for k in range(i + 1, j):
                for cat_id in range(num_categories):
                    s = scores[(i, j)][cat_id].item() + best[i][k][3] + best[k][j][3]
                    if s > best[i][j][3]:
                        best[i][j] = (cat_id, k, s)

    return best
```

## Evaluation: Parseval and UAS/LAS

Parser evaluation traditionally uses **Parseval metrics**:
- **Labeled precision/recall/F1**: How many constituents in the predicted tree match constituents in the reference tree, including labels?
- **Unlabeled precision/recall**: Just the spans, ignoring labels.

More recent approaches evaluate using **constituency-to-dependency conversion** and standard dependency metrics.

```python
def eval_parseval(pred_trees, ref_trees):
    """Evaluate constituent matching (Parseval)"""
    total_pred = sum(count_constituents(t) for t in pred_trees)
    total_ref  = sum(count_constituents(t) for t in ref_trees)
    matches = sum(count_matches(p, r) for p, r in zip(pred_trees, ref_trees))

    precision = matches / total_pred if total_pred > 0 else 0
    recall    = matches / total_ref  if total_ref  > 0 else 0
    f1        = 2 * precision * recall / (precision + recall) if (precision + recall) > 0 else 0
    return {'precision': precision, 'recall': recall, 'f1': f1}
```

## Key Concepts

- **Context-free grammar (CFG)**: Formal system with rules $A \rightarrow \alpha$ generating hierarchical structures
- **Constituent**: A group of words that functions as a unit within a sentence (NP, VP, PP, etc.)
- **CKY/CYK algorithm**: $O(n^3)$ dynamic programming parsing for CNF grammars
- **Shift-reduce parsing**: Bottom-up stack-based parsing with neural action scoring
- **Chart parsing**: Dynamic programming over an agenda of candidate constituents
- **Parseval metrics**: Constituent-level precision, recall, and F1
